O que é Dualboot?
👨‍🏫 Prof. Cristovam Azevedo
🟢 Ao Vivo

Dois Sistemas, Uma Máquina

O Dualboot permite instalar dois ou mais Sistemas Operacionais (como Windows e Linux) no mesmo computador. Ao ligar a máquina, você escolhe qual deseja usar.

🏠
Analogia: A Casa Dividida

Imagine o seu HD (disco) como um terreno grande. Inicialmente, o Windows ocupa o terreno todo com uma casa só. Fazer Dualboot é como colocar um muro no meio do terreno e construir uma segunda casa para o Linux. As duas casas ficam no mesmo endereço físico, mas os moradores não se misturam. A portaria (GRUB) pergunta em qual casa você quer entrar quando chega.

Muitos iniciantes têm medo do Dualboot. Avalie as afirmações abaixo como "Mito" ou "Verdade".

💡 Por que usar Dualboot?

Ter dois sistemas no mesmo computador não é apenas "uma curiosidade técnica". É uma habilidade profissional e acadêmica cada vez mais valorizada no mercado de tecnologia.

🧰
Analogia: A Caixa de Ferramentas

Imagine um eletricista que só usa uma chave de fenda para tudo. Ele até consegue trabalhar, mas será muito limitado. Um profissional completo tem várias ferramentas — e sabe qual usar em cada situação. O Dualboot é isso: você passa a ter o Windows (para jogos, programas comerciais) e o Linux (para programação, servidores, segurança, automação) disponíveis na mesma máquina.

👨‍💻
Mercado de TI

Mais de 90% dos servidores do mundo rodam Linux. Se quiser trabalhar com servidores, nuvem (AWS, Google Cloud), DevOps ou segurança, conhecer Linux é obrigatório.

🎓
Cursos Técnicos e Faculdade

Muitas ferramentas de programação funcionam muito melhor no Linux: Python, GCC, Docker, Apache, PostgreSQL.

🔐
Segurança e Ethical Hacking

Ferramentas como Kali Linux (usada em concursos de segurança) só existem no Linux. O campo de Cybersegurança exige domínio do sistema.

💸
É Gratuito!

O Linux não custa nada. Para quem não tem condições de pagar licença do Windows, o Linux é uma alternativa profissional e completa, usada por Google e Amazon.

⚡
Desempenho

O Linux usa menos RAM e processador que o Windows. PCs mais antigos ganham uma nova vida com distros leves como Linux Mint ou Ubuntu.

🌍
Código Aberto

No Linux, qualquer pessoa pode ver, estudar e modificar o código do sistema — ideal para quem está aprendendo e quer entender como tudo funciona por dentro.

Particionamento de Disco

Antes de instalar o Linux, precisamos "encolher" a casa do Windows para abrir espaço. Isso se chama Reduzir Volume (Shrink).

✂️
Analogia: Fatiando uma Pizza

O disco é como uma pizza grande que veio inteira para o Windows (C:). Nós precisamos cortar uma fatia (Espaço Não Alocado) para instalar os ingredientes do Linux nela. Se não separarmos o espaço antes, o Linux pode sobrescrever os arquivos do Windows!

A Fronteira: BIOS / UEFI

Para instalar o segundo sistema, o computador precisa ler o Pendrive de instalação antes do HD. Configuramos isso na BIOS/UEFI.

🚪
Analogia: O Porteiro do Prédio

A BIOS é o porteiro. Por padrão, ele tem ordem (Boot Priority) de deixar apenas o "Sr. Windows" (HD) entrar. Para instalar o Linux, precisamos avisar o porteiro para atender primeiro o "Visitante" (Pendrive USB). Além disso, precisamos desativar o "Segurança Rigorosa" (Secure Boot) que barra sistemas operacionais que não têm a "assinatura da Microsoft".

⚙️ Atividade — Configure a BIOS ✅ Concluída

Para darmos boot no pendrive de instalação do Linux, você deve configurar a tela azul acima. Cumpra os 3 requisitos para passar.

  • ❌ Secure Boot deve estar Disabled
  • ❌ Fast Boot deve estar Disabled
  • ❌ USB Flash Drive deve ser a Boot Option #1

GRUB: O Gerenciador de Boot

Depois que tudo está instalado, quem manda na inicialização é o GRUB (GRand Unified Bootloader). É a famosa "telinha preta" que aparece ao ligar o PC.
